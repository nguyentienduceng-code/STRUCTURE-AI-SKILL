# Hướng dẫn Sử dụng Công thức và Ký hiệu

## 1. Ký hiệu Toán học

### So sánh
| Ký hiệu | Ý nghĩa | Ví dụ |
|----------|---------|--------|
| `≤` | Nhỏ hơn hoặc bằng | η ≤ 1.0 |
| `≥` | Lớn hơn hoặc bằng | ρ ≥ 0.05% |
| `≠` | Khác | |
| `±` | Cộng trừ | L/500 ± 5% |

### Số mũ
| Ký hiệu | Ý nghĩa | Markdown |
|----------|---------|----------|
| `²` | Bình phương | `x²` hoặc `x^2` |

| `⁴` | Bậc 4 | `z⁴` |

## 6. Công thức Cấu kiện BTCT

### Cốt thép chịu uốn

```
A_s,req = M / (f_y/γ_s × z)

α = A_s × f_y / (b × f_c)

x = α × d / β₁

η = A_s,req / A_s,prov ≤ 1.0
```

### Cốt thép chịu cắt

```
V_c = 0.3 × φ × f_ct × b × d

V_sw = V - V_c

A_sw = V_sw × s / (f_yw × d)

η = V / (V_c + V_sw) ≤ 1.0
```

### Kiểm tra nứt

```
a_crc = 50 × (1 - k) × (σ_s × k³ + ρ × σ_s × (1 - k)²) / E_s

η = a_crc / a_crc,max ≤ 1.0
```

### Kiểm tra võng

```
f = 5 × q × L⁴ / (384 × E × I)

η = f / f_gh ≤ 1.0
```

## 7. Công thức Cấu kiện Thép

### Kiểm tra bền

```
σ = M / W + N / A ≤ f_y / γ_M0

τ = V / (A_v / √3) ≤ f_y / (γ_M0 × √3)
```

### Kiểm tra LTB

```
λ_LT = √(W × f_y / M_cr)

Φ_LT = 0.5 × [1 + α × (λ_LT - 0.2) + λ_LT²]

χ_LT = 1 / (Φ_LT + √(Φ_LT² - λ_LT²))

M_b,Rd = χ_LT × W × f_y / γ_M1

η = M / M_b,Rd ≤ 1.0
```

### Kiểm tra ổn định cục bộ

```
λ_p = 0.749 × √(f_y / σ_cr)

λ_pw = 1.908 × √(f_y / σ_cr,w)

η = λ / λ_p ≤ 1.0
```
